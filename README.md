# Shiv-Darshan-Homestay

Official web application for **Shiv Darshan Homestay**, located in Haat, Dharchula Dehat, Pithoragarh, Uttarakhand.

## 🚩 Overview

Shiv Darshan Homestay offers boutique Himalayan accommodation and authentic Kumaoni hospitality along the sacred Adi Kailash & Om Parvat route. Hosted by **Govind Singh Dhami**.

- **Location**: Haat, Dharchula Dehat, Pithoragarh, Uttarakhand 262545
- **Google Maps**: [Directions Link](https://maps.app.goo.gl/rQN7wv5mMmsVjdkQ6?g_st=aw)
- **Instagram**: [@shiv__darshan12345](https://instagram.com/shiv__darshan12345?utm_source=qr&mdxt=bHg3bnRxNWc2djE2)

## ✨ Features

- **60 FPS Animated Shiva Temple**: GPU-accelerated animated temple scene in the Hero section with sacred Shikhar, Kalash, glowing Trishul aura, swinging bells, and devotees offering Aarti & Pranam with scroll-driven zoom-out.
- **16:9 Cloudinary Video Tours**: Responsive dual video walkthrough player with mobile touch swipe gestures, slider arrows, and switcher tabs.
- **Interactive Room Booking**: Room showcase with high-res photo gallery, price breakdown, amenities, and direct WhatsApp / EmailJS booking system.
- **Local Highlights & Services**: Helipad transfer info (4 km), home-cooked Kumaoni meals, evening bonfires, and secure parking.
- **Fully Responsive & Accessible**: Mobile-first design, fluid drawer navigation, floating docked WhatsApp booking pill, and smooth scroll restoration.

## 🚀 Available Scripts

In the project root directory, you can run:

### `npm start`
Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm test`
Runs the automated Jest test suite.

### `npm run build`
Builds the optimized production-ready bundle into the `build` directory.
